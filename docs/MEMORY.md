## 2. 批跑运维铁律（事故换来的）

1. **pkill 自匹配**：`pkill -f` 模式与自身命令行任何文本不得有正则重叠（三次翻车）。安全写法 `"breadth_alpha[.]py"`；杀进程与查状态分开两条 ssh
2. **等待循环禁令**：批脚本禁用 `while pgrep xargs` —— 多等待者互相复活批任务（42 waiter 事故）。用单链脚本顺序执行
   2b. **杀 xargs 批的顺序**：先 pkill wrapper 函数名（如 `run_in[d]`，它在 bash -c 命令行里），再杀 worker；只杀 worker 会被 xargs 立刻补位"复活"（08-22 实证）
   2c. **重放批并发按内存算不按核算**：2015 矩阵重放每进程峰值 ~25G，041(503G) 上 **P6 稳、P8 顶格、P16 曾打爆内存**（08-22 事故：load 466、可用内存 5G、机器准失联 3 分钟）。GF1 当年用 P8 是有原因的
3. **ssh 后台任务**：`setsid` + `</dev/null` + 重定向，或 `ssh -f`；否则 ssh 挂住像"卡住"
4. xargs 的 cmds 文件**不可原地覆盖**（fd 偏移混乱），换新文件名
5. 长任务：后台起 + 日志落盘 + 延时读日志；**禁止前台跑全量回测**
6. **实验登记制（2026-08-21 起）**：每次 launch 实验同时在 `docs/experiment_board.md` 登记（机器/标签/启动/**预计结束**/日志/接力条件），收割后移「已收割」写判决；看板是唯一权威，不翻聊天记录
7. **ssh 长命令会被截断拼接**（2026-08-18 事故：多行 heredoc+嵌套引号碎成乱码，批任务静默未启动）→ 批脚本一律本地写文件 + scp + 短命令启动；启动后必验 `ps | grep -c` 和日志头几行

## 3. 实验方法论约定

### 种子预算协议（2026-08-17 定稿）
- **探索：固定 5 种子组 [1, 42, 123, 888, 2024]**（误差中位 4.4pp，漏杀 8%）
- 5 种子下差 <20pp = 不可分，**不得淘汰**；敏感排序上 10 种子（漏杀 0.3%）
- **上线 gate / 定稿数字：必须 20 种子**。省 ~75% 算力

### 回测必知坑（wf_v35_breadth_alpha.py）
- `--skip-boards` / `--exclude-feats` 是**逗号分隔单字符串**，不是 nargs
- 种子后缀已强制进输出文件名（2026-08-17 根治）+ 原子落盘，但 tag 带上种子仍是好习惯
- 用 `scripts/verify_tag_config.py` 防配置漂移（实测拦过 `--tranche-n` 默认值坑）
- 上线前过 `scripts/check_deploy_gate.py` 四关（一致性/无掩码/无零方差/覆盖率）
- 执行层旗标（全默认关=基线位级不变）：`--fill-daily`（闲钱日补）/`--roll-rank M`（到期宽续持）/`--rank-stop K`（已判死勿用）/`--regime-reenter`/`--regime-soft-low`（择时软化，已判死勿用）；改执行层参数用 `--load-preds` 重放，每跑 ~1.5 分钟，模型参数必须与缓存一致；新旗标上线前必做无旗标位级回归（s42 重放对数字）

### 判断特征集的铁则
- **不能只看 IC，必须看组合层超额/IR**（V24A 的 IC t 值 6.375 更高却是负超额——掩码特征给漂亮 IC，组合层拿不到）
- 必做逐年 + 留一年检验（`scripts/yearly_robust.py`），防"单年撑全场"（FBTR2/V24A 的 2025 依赖病）

## 4. 数据体系关键事实

### 逐笔数据（5TB，2017-01~至今，全市场 7817 只）
- **沪深编码完全不同**（搞错=静默垃圾）：SH 撤单在委托文件 `委托类型=='D'`；SZ 撤单在**成交**文件 `成交代码=='C'`，方向看叫买/叫卖序号
- 价格单位两所都是 **1/10000 元**；`时间` 是 HHMMSSmmm 非线性，分箱先换算当日秒数
- **SH 逐笔委托 2022 起才有**（2017-21 全缺）→ 委托类特征起点 2022-01；扩窗时委托 3 列（ord_amt_ratio/cxl_rate_b/ord_net_l）SH=NaN 口径（SZ 有值，LightGBM 原生处理，需消融验证）
- **供应商多批次格式不齐（2026-08-19 回填踩坑）**：2018-07~2019-05 批次 CSV 列头逗号后带空格，精确 usecols 静默丢整天（首跑 136 天全灭）。_rd 已改 strip 匹配。铁律：批回填 QC 必须数"应有 vs 实有"天数
- **tick 面板历史**：生产 tick_micro/ 从 2019-06-03 起；2017-01~2019-05 回填在 040 tick_micro_bf2017/（583 天，QC 对账 1.0000，扩窗阶段二时并入）；data/raw/kline 个股日线只回到 2019，全历史用 kline_pit.parquet（1990 起）
- `trd_net_*` 交易所相关（撮合粒度不同）→ **横截面标准化必须按交易所分组**
- 逐笔 alpha 随陈化衰减：d-1 超额 12.55% → d-5 只剩 4.45% → **日更管线是生产关键件**
- 但**单独一天的新鲜度测不出价**（2026-08-19 陈化定价实验，负结果）：固定 V24PUT 80 特征集、72 矩阵列 shift(1)、5 种子配对，陈化臂中位反而 +5.4pp（区间 -62~+24pp）——日线特征多为 ma 平滑量，晚一天损失 ≪ 种子噪声；-2pp/天是 5 天累积才可测 → **当天选股不立项**（口径：mkt/ovn 现算未陈化，测得为下界）

### 执行层的钱在哪（2026-08-18 八臂网格定调）
- **FDRR8（fill-daily + roll-rank 8）= 唯一大赢家**：20 种子官方 +73.5%/夏普 1.00 vs 基线 +32.8%/0.61（20bp 口径）。同一张排名表：中途踢人（rank-stop）越紧越惨，到期宽续持+闲钱日补白捡 40pp——**排名噪声区“不动手”对、“动手”错**；roll-rank 单用无增益，与 fill-daily 是纯协同
- 执行价用收盘价即最优（日内择时买卖两侧全灭，机制对称）
- 每日调仓死于成本（38.9% 摩擦吞掉全部 alpha），**5d 持有是谷底正中**（FD 下重扫 3/8 天两头塔）
- breadth 择时的**全有全无就是对的**（滞回/半仓档全微负）；择时是风控层不是收益层
- **选股池 630→1500 扩容判死**：无增益、回撤翻倍、FDRR8 不迁移；1500 池 alpha 集中在 20cm 板块，与生产线排 30/688 相冲突

### 骑在信号头上的“聪明覆盖层”全军覆没（2026-08-31 汇总）
- 名单：GT 择时替换（20 种子屠杀级否决）、GFV3 门控（翻案关掉）、**G1 跳空弃买**、**H1 长假清仓**、静态排名平均融合 BLG3、rank-stop、滞回/半仓档
- **G1 的剂量-反应曲线是最硬的证据**：干预越频繁亏越多（3% 阈值触发 65 次 = -23.3pp；5% 触发 21~31 次 = -8.7pp；外推干预 0 次≈最优）—— **执行日低开在期望上是机会不是信息**，策略 alpha 本身就含接飞刀成分
- 推论：“出大事就别照单”这类直觉规则，99% 的事件日正确动作就是**照单执行**；人的作用只剩兜底回测窗里没出现过的极端尾部（停牌潮/立案/跌停买不进这类**执行可行性**问题，而非方向判断）
- **宏观事件并不稀少**（FOMC 8 次/年、CPI/PCE/非农各 12 次/年，几乎每周都有事件落进隔夜盲区），但“事件发生”≠“干预优于照单”—— 这两个命题必须分开

### 其他
- 线上 `slippage=0.002` 是资金缓冲不是成本模型，**别归零**（会吃现金余量增加拒单）
- **`--skip-boards` 在 `--load-preds` 重放下是空操作**（2026-08-31 LSW 踩到）：df 级板块过滤在 `wf_v35` L731 写着 `if SKIP_BOARDS and not args.load_preds`；而 preds 缓存本身就是带板块过滤训出来的（候选池里没 30x/688 代码，`n_board_skip` 恒 0）。→ **“全市场”变体无法用重放测，去掉 flag 加不回 preds 里不存在的股票**，必须重训。征候：两臂逐种子 20/20 完全相同就是重复臂，先查 JSON 里的参数字段和计数器再下结论
