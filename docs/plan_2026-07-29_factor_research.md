# 第一部分: 今晚查出的四个问题

## 1. 一半的特征对当前任务在数学上零信息

标签是按日期 demean 的截面收益 `y = fwd_5d_ret - 当日均值`。
对这种标签, **任何在同一天对所有股票取同值的特征, 单独预测能力恒为 0**。

实测 (`diag_feature_information.py`):

| | 数量 | 占比 |
|---|---|---|
| 候选特征总数 | 421 | 100% |
| 截面变异比 < 1% (市场级常数) | **215** | **51%** |
| 真正有截面变异 | 206 | 49% |

市场级特征包括: 全部商品价格(沪金/沪铜/六氟化钨...)、汇率(美元指数/USDCNH/
USDJPY)、中美国债收益率、中美PMI、全球指数期货(标普/道指/纳指/SOX/A50)、
全市场事件聚合(tev_all_*)。它们每天只有一个值。

树模型仍可能在这些特征上分裂, 但那种分裂会把当天**所有**股票分到同一侧,
等价于**按日期切分训练集** —— 是记忆训练区间, 不是学习选股规律。

## 2. 更糟: 这些特征的 MA 派生靠停牌日历伪造截面变异, 且排在重要度第一

`feature_engine.py:1216-1221` 在**单只股票内部**对几乎所有列做
`rolling(5/20).mean()`。市场级序列原始值截面变异精确为 0, 但每只股票停牌日
不同 -> 滚动窗口覆盖的日历不同 -> MA 派生凭空产生了截面差异。

实测 (`diag_ma_artifact.py`):

| 母特征 | 原始 | `_ma5` | `_ma20` |
|---|---|---|---|
| `usdind` 美元指数 | 0.00000 | 0.00132 | 0.00520 |
| `cn5y` 中国5年国债 | 0.00000 | 0.00146 | 0.00554 |
| `cn_commodity_idx_chg_5d` | 0.00000 | 0.00357 | 0.01015 |

这种"变异"与**近20日缺勤天数**显著相关:

```
a50_futures_chg_21d_ma20  rho=+0.1370 (t=3.4)
a50_futures_z_21d_ma20    rho=+0.1511 (t=3.1)
a50_futures_chg_5d_ma20   rho=+0.0950 (t=2.3)
```

即它编码的是"这只股票最近停过牌吗"。而修复前, 特征重要度 top10 是:

```

dj_futures_chg_2d_ma20, sox_chg_5d_ma20, a50_futures_chg_5d_ma20, ...
```

**排名第一的特征是日历假象。**

按母特征剔除后 (`--drop-market-wide 0.01`, 345 -> 183 个候选), top10 变为:

```

con_ret_1d_ma10_ma20, roe, revenue, ret_5d_ma20, con_mf_net_ma10_ma20
```

全部是有经济含义的个股截面特征。

## 4. 特征数量对 IC 没有影响, 因为独立样本不够

`sweep_n_features.py` (只改 n_features, 其余完全相同):

| n_features | IC | IC t值 | 总收益 |
|---|---|---|---|
| 20 | +0.0217 | 2.32 | 64.5% |
| 40 | +0.0200 | 2.24 | 73.5% |
| 60 | +0.0206 | 2.42 | 69.5% |
| 80 | +0.0275 | 3.20 | 25.3% |

IC 全部落在 0.0200~0.0275, 而 IC 的标准误约 0.008 -> **2SE = 0.016,
所有差异都在噪声内**。特征数从 20 增到 80, IC 没有可测量的变化。
而总收益从 25.3% 到 73.5% 乱跳 —— 再次印证总收益 t≈1 无信息量。

根本原因:

```
独立信息维度 (去市场级 + 去MA派生 + |r|>0.7 去相关) = 58
独立样本区块 (255 交易日 / 5 日重叠标签)           = 51
比值 = 1.14  > 1
```

**参数维度超过独立样本数**, 过拟合是数学必然。这也是特征重要度种子间
变异系数高达 0.64~0.90 的根源 —— 不是代码 bug, 是样本不够。

# 第二部分: 直接回答你的问题

## Q1: 理论上是不是信息越多越好?

**不是。** 分三层说明。

### (a) 数学层: 有些信息对当前任务的贡献恒为 0

对截面 demean 的标签, 市场级信息的**边际贡献严格为 0**(只能通过与个股
特征交互间接起作用)。今晚证实这类占了 52%。

这不是"效果差一点", 是**结构性无效**。

### (b) 统计层: 每多一个候选特征, 就多一次假阳性机会

在 51 个独立样本区块上筛 421 个特征。即使全是纯噪声, 按 |t|>2 筛选,
期望也能筛出 `421 × 5% ≈ 21` 个"显著"因子。

实测 |t|>2 的有 59/116 = 51%, 远高于 5%, 说明确有真信号; 但同时也说明
**假阳性绝对数量不小**, 且无法分辨哪些是真的。

### (c) 但"信息"和"特征列"是两回事

正确的信息量度量不是特征数, 而是:

```
有效信息 ≈ 独立观测数 × 单位观测信噪比 × 与已有信息的正交性
```

当前瓶颈全在**第一项**:
- 股票池 497 只 (全市场约 5000)
- 筛选期独立时间区块 51 个

**加特征列改善不了任何一项。** 这就是为什么 n_features 20->120 毫无变化。

### 正确的"增加信息"方式 (按性价比)

| 做法 | 有效信息增量 | 成本 |
|---|---|---|
| 股票池 497 -> 全市场 5000 | 截面估计精度 ×√10 | 采集 1-2 天 |
| 历史 2022 -> 2015 | 时间区块 ×3 | 采集 1 天 |
| 加一个正交新数据源 | 取决于正交性 | 数天 |
| 再加 100 个现有数据的衍生列 | **≈ 0** | 0 |

## Q2: 怎么选重要信息来学习?

**不能靠 gain 重要度排序** —— 今晚证明它会把停牌日历假象排到第一名。

建议四道关, 依次过滤:

**第一关 结构性过滤 (机械, 无需拟合)**
- 截面变异比 >= 1%, 且**按母特征判定**(MA 派生随母特征一起剔除)
- 已实现: `--drop-market-wide 0.01`

**第二关 符号稳定性 (核心, 当前完全缺失)**
- 把筛选期切成 N 个滚动窗口, 每个窗口算一次 IC
- 判据不是"平均 |t| 高", 而是 **IC 符号一致率 >= 70%**
- 今晚数据: 用单期 |t|>=3 挑出的因子, 50% 在测试期翻转;
  若改用符号一致率, 应能提前排除 roe/eps/macd 这类

**第三关 经济逻辑**
- 说得出为什么它该有效。低波动、现金流、营收规模都说得通;
  `dj_futures_chg_1d_ma20` 说不通 —— 说不通的即使 t 值高也不要

**第四关 增量价值**
- 加进去之后, **头部分层收益**有没有提升(不是 IC, 见 Q3)

## Q3: 模型框架有待改善的地方

### 3.1 最重要: 评价指标要从 IC 换成头部分层收益

今晚做了一个关键对照 (`diag_decile_monotonicity.py` vs `diag_simple_baseline.py`):

| | IC | IC t值 | **第1层收益** | 多空 t |
|---|---|---|---|---|
| 80特征 LightGBM | +0.0275 | 3.20 | **+1.324%/期** | **+4.58** |
| 12因子等权合成 | +0.0276 | 3.57 | +0.104%/期 | -1.76 |

**IC 完全打平, 但头部差 13 倍。**

原因: IC 衡量全截面秩相关, 而策略只买前 3 名。简单合成的第10层(最不看好)
平均收益反而最高(+0.429%), 因为高波动股的右尾把均值拉起来 —— 这在 IC 上
反映不出来。

ML 模型的分层是这样的:

| 层 | 收益/期 | t | |
|---|---|---|---|
| 1 | +1.324% | 5.64 | 显著 |
| 2 | +0.699% | 3.95 | 显著 |
| 3 | +0.403% | 2.52 | 显著 |
| 4 | +0.303% | 2.10 | 显著 |
| 5~10 | 0.18~0.35% | 全部 <2 | 平坦 |

**模型会"挑出好股票", 但不会"全排序"。** 前 40% 有效, 后 60% 是噪声。
这对只买头部的策略是好消息, 也说明 ML 相比线性合成确有增量价值。

> 所以我昨晚说的"改用 IC 做决策"**不够准确**, 应改为:
> **主指标 = 第1层(前10%)相对截面均值的超额收益及其 t 值**;
> IC 只作辅助。

### 3.2 目标函数与用途不匹配

现在用 `objective=l2` 拟合 demean 后的收益, 优化的是**整个截面的 MSE**,
大部分模型容量花在预测中间那些你根本不会买的股票上。

而分层结果显示模型只在前 40% 有效。应该:
- 试 `--objective rank` (lambdarank, 已实现但从未启用)
- 或改成二分类: 标签 = 是否属于当日前 20%
- 或分位数回归, 只拟合上尾

### 3.3 因子筛选应该滚动, 而不是一次定终身

现在: 用 2023-09-19 之前的数据筛一次, 用到 2026。
50% 符号翻转说明这不成立。

应改为: 每 6~12 个月用最近 2 年数据重筛一次(严格 PIT, 只用当时可得数据)。

### 3.4 缺少集成, 单模型方差大

特征筛选的随机性直接传导到最终结果(种子间变异系数 0.64~0.90)。
最便宜的改进: **多种子 / 多特征子集训练, 预测值按 rank 平均**。
几乎无风险, 通常能稳定提升 IR。

### 3.5 训练/验证之间没有 purge & embargo

标签是 5 日重叠的。若训练集末尾与预测日相邻, 存在信息重叠。
应在训练集尾部留至少 `LABEL_HORIZON` 天的间隔。
(需要确认当前 walk-forward 是否已处理, 尚未核实)

### 3.6 风格暴露没有常规监控

`--neutralize-style` 有开关但默认关。今晚发现最强的因子是 `atr_pct_ma20`
(低波动), 说明模型很可能带着强烈的**低波动风格暴露**。
这在 2023-26 有效, 但它是风格 beta 而非 alpha, 需要单独度量。

# 第三部分: 从"能获取的信息"上, 还缺什么

现有六维: 技术面 / 资金流 / 融资融券 / 事件公告 / 基本面 / 宏观商品。

按**性价比**排序的缺口:

## 1. 北向资金持股比例 (最高优先级)

- **为什么**: 沪深港通持股比例的变化是 A 股近十年最稳健的截面因子之一,
  且与现有资金流(主力净流入)**来源不同、逻辑不同**(外资配置行为 vs 日内大单)
- **可得性**: akshare `stock_hsgt_hold_stock_em` / `stock_hsgt_individual_em`, 免费, 日频
- **当前状态**: **完全没有采集**
- **预期**: 这是唯一一个"已知强因子 + 免费 + 日频 + 完全没用上"的项

## 2. 分析师一致预期修正

- **为什么**: 预期 EPS 的修正方向/幅度(analyst revision)是全球最稳健的因子之一,
  逻辑是信息扩散的持续性。与现有基本面(已公布的历史财报)**完全正交** ——
  一个是过去, 一个是预期
- **可得性**: iFinD 有 (你已有账号)
- **当前状态**: 没有

## 3. 龙虎榜席位

- **为什么**: A 股特有。游资席位 / 机构专用席位的进出, 与主力资金流不同,
  是**带身份标签**的资金信息
- **可得性**: akshare `stock_lhb_detail_em`, 免费
- **当前状态**: 没有

## 4. 财报季度化 + SUE (标准化预期外盈余)

- **为什么**: 当前基本面是**年度**数据(`{yr}-06-30`)且只有 12 个字段,
  信息频率太低。季度环比/同比加速度、SUE 是经典因子
- **当前状态**: 有年度数据, 缺季度化和衍生
- **注意**: 必须严格 PIT (已有 `_fund_pub_date` 处理发布日偏移, 逻辑正确)

## 5. 日内微观结构

- **为什么**: 当前只有日频 OHLCV + 隔夜收益。已实现波动率、买卖压力不平衡、
  尾盘异动都是独立信息
- **可得性**: akshare 分钟线, 免费但数据量大
- **优先级**: 最低, 工程量最大

- ❌ 用 ¥20,000 实盘跑当前策略 —— 8 个配置 7 个亏损
- ❌ 用总收益调参 —— t≈1, 在拟合噪声
- ❌ 换更复杂的模型(深度学习等) —— 样本量连 LightGBM 都喂不饱

---

# 一句话总结

**当前瓶颈不是模型不够强, 而是 (a) 一半特征对任务零信息且其中最"重要"的
是停牌日历假象, (b) 因子符号半数会翻转却从不复检, (c) 独立样本(51 个区块)
比参数维度(58)还少。**

**解法的优先级是: 先清理无效特征 -> 再建立稳定性筛选和正确的评价指标 ->
再扩样本 -> 最后才是加新数据源。加特征列是唯一被证明完全无效的方向。**

其中 (a) 今晚已经修完并验证: 一行开关 `--drop-market-wide 0.01`,
IC +0.0275 -> +0.0482 (t 3.20 -> 6.48), 第1层 t 5.57 -> 6.57,
2023 年多空 t 从 -2.36 翻正到 +4.68。这是今晚唯一确定性的净收益。
